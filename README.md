# Leanivio v2

Interactive Next.js prototype for a personalized nutrition business.

## Included
- Responsive blue landing page
- Three-step questionnaire
- U.S. and metric units
- Dynamic calorie, macro, water, BMI, and timeline estimates
- Dietary preferences, allergies, dislikes, budget, cooking time, and preferred store
- Personalized locked-plan preview
- Stripe checkout placeholder
- Vercel-ready configuration

## Upload to GitHub from a phone
1. Open the `leanivio` repository.
2. Tap **uploading an existing file**.
3. Extract this ZIP on your phone first.
4. Select the contents of the extracted folder, not the outer folder itself.
5. Commit the files to the `main` branch.
6. Connect the repository to Vercel.

## Local development
```bash
npm install
npm run dev
```

## Important
The nutrition calculations are estimates for a general wellness product. Before launch, have the content reviewed by a registered dietitian and add complete Terms, Privacy Policy, Refund Policy, and health disclaimers.
